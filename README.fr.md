![L’atelier Wheel and Form](site/assets/screenshots/workbench-body.png)

Wheel and Form est une application de bureau Windows qui réunit les tâches de fichiers pour lesquelles on visite habituellement cinq sites différents. Convertissez, compressez, extrayez, recadrez, coupez, fusionnez, masquez et organisez vos fichiers localement. Commencez un glisser, maintenez une touche et terminez sur une roue radiale. Pas de compte, pas d’envoi, pas de file d’attente dans le cloud.

- **303 conversions** entre **53 formats d’entrée** et **39 formats de sortie**
- **26 outils ciblés** pour les images, la vidéo, l’audio, les PDF, les documents et les archives
- **6 actions de fichier** — partager/copier, aperçu flottant, dupliquer, déplacer, copier le chemin, ouvrir un terminal
- **Roue de bureau à l’échelle du système** — utilisez-la depuis l’Explorateur, le bureau ou une boîte de dialogue sans ouvrir l’application
- **Intégration native au shell Windows** — révélez les sorties, ouvrez les fichiers, copiez les chemins et ouvrez un terminal dans le dossier du fichier
- **Mises à jour en un clic** — vérifiées avec la somme de contrôle de la version GitHub et installées après un redémarrage
- **Local par défaut** — vos fichiers sont lus et écrits sur votre PC

---

## L’atelier

Mettez un lot hétérogène en file d’attente, choisissez une destination pour chaque fichier, puis convertissez. Les sorties sont créées à côté du fichier source par défaut, si bien que le fichier de départ ne bouge jamais. Chaque opération écrit un nouveau fichier.

![File d’attente avec une conversion terminée](site/assets/screenshots/conversion-done.png)

- Files d’attente mixtes d’images, PDF, documents, audio, vidéo et archives
- Une destination par fichier au lieu d’un mode global unique
- Une progression réelle, des erreurs lisibles et un journal d’activité persistant
- Ouvrez, révélez ou partagez un fichier terminé sans quitter l’atelier

## La roue

La roue est le raccourci clavier de toute l’application. Maintenez un modificateur pendant que vous glissez un fichier : les destinations correspondantes apparaissent sous le pointeur.

| Touche | Roue | Ce qu’elle affiche |
| --- | --- | --- |
| `Shift` | Formats | Les formats de sortie du fichier |
| `Ctrl` | Tools | Les opérations ciblées pour ce type de fichier |
| `Alt` | Actions | Partager/copier, aperçu, dupliquer, déplacer, copier le chemin, terminal |

![Roue des formats au-dessus de l’atelier](site/assets/screenshots/wheel.png)

Relâchez sur une destination pour l’exécuter. Les flèches et `Enter` fonctionnent aussi. La roue se souvient du point de départ du glisser et garde le résultat à côté de l’original.

### En dehors de l’application

La même roue fonctionne partout dans Windows. Commencez à glisser un fichier dans l’Explorateur, sur le bureau ou depuis une boîte de dialogue, puis maintenez `Shift`, `Ctrl` ou `Alt`. La roue apparaît au pointeur sur l’écran actif. Appuyez sur `Escape` pour annuler.

![Roue système au-dessus de l’Explorateur Windows](site/assets/screenshots/desktop-wheel-crop.png)

En dehors de l’application, les résultats sont toujours écrits à côté de l’original et la source n’est jamais modifiée. Une petite carte d’état montre la progression, puis permet de révéler le résultat ou d’ouvrir la configuration des moteurs si quelque chose manque.

Fermer la fenêtre principale laisse Wheel and Form actif dans la zone de notification. Cliquez avec le bouton droit sur l’icône de la barre d’état pour rouvrir l’application, activer la roue de bureau, ouvrir Settings ou quitter.

## Outils

26 outils ciblés pour la dernière étape. Chaque outil s’exécute localement, affiche un aperçu du résultat et laisse l’original intact.

![Outil de recadrage avec aperçu en direct](site/assets/screenshots/tool-crop.png)

Compress · Remove Metadata · Edit Image · Annotate · Add Background · Crop · Redact · Normalize Audio · Mute Video · Trim Video · Split PDF · Organize PDF · Extract Archive · Create PDF · Merge PDFs · Crop Video · Change Speed · Join Videos · Snapshots · Split Video · Audio to Video · Trim Audio · Audio Channels · Bleep Audio · Redact Video · Create Collage

La séparation, la fusion, l’organisation et la création de PDF sont gérées dans le processus avec `pdf-lib`, donc elles fonctionnent sans moteur externe.

## Local par défaut

Pas de compte. Pas d’envoi. Pas de file d’attente côté serveur. Les conversions, les outils et les aperçus s’exécutent sur votre machine. Les réglages vivent dans un petit fichier JSON du dossier de données utilisateur d’Electron ; aucune télémétrie n’est envoyée.

| Réglages de sortie | Réglages des moteurs |
| --- | --- |
| ![Réglages de sortie](site/assets/screenshots/settings-output.png) | ![Réglages des moteurs](site/assets/screenshots/settings-engines.png) |

Wheel and Form n’effectue des requêtes réseau que dans deux cas :

- vérifier les versions GitHub pour mettre à jour l’application ;
- installer un moteur de conversion via `winget` lorsque vous le demandez.

Les vérifications de mise à jour lisent uniquement les métadonnées publiques de version. Les téléchargements ne contiennent que la nouvelle compilation de l’application. Aucun nom de fichier, contenu, donnée d’usage ou donnée personnelle n’est envoyé.

## Configuration requise et moteurs

Wheel and Form détecte les moteurs de conversion courants à l’exécution. Les moteurs manquants peuvent être installés depuis **Settings → Engines** avec `winget`, ou vous pouvez indiquer à l’application un exécutable existant.

| Moteur | Utilisé pour | Obligatoire ? |
| --- | --- | --- |
| [FFmpeg](https://ffmpeg.org/) | conversion vidéo/audio, coupe, silence, captures, repli raster de base | Recommandé |
| [ImageMagick](https://imagemagick.org/) | retouches avancées, suppression de métadonnées, recadrage, annotation, masquage | Facultatif |
| [Pandoc](https://pandoc.org/) | conversion de documents texte/Markdown/HTML | Facultatif |
| [LibreOffice](https://www.libreoffice.org/) | conversion de documents Office et sortie PDF | Facultatif |
| [7-Zip](https://www.7-zip.org/) | création et extraction d’archives | Facultatif |
| [Ghostscript](https://www.ghostscript.com/) | rasterisation PDF et extraction de texte PDF | Facultatif |

Les outils PDF fonctionnent immédiatement. Les conversions raster courantes (PNG/JPG/WEBP/TIFF/GIF) se rabattent sur FFmpeg lorsque ImageMagick n’est pas disponible.

## Installation

1. Ouvrez la [dernière version](https://github.com/Nolane-x/Wheel-and-form/releases/latest).
2. Téléchargez `Wheel-and-Form-Setup-<version>.exe`.
3. Lancez l’installateur et choisissez un dossier de destination. Une installation par utilisateur ne nécessite pas de compte administrateur.

L’installateur n’est pas signé, Windows SmartScreen peut donc demander une confirmation au premier lancement.

## Mises à jour

La version installée vérifie GitHub Releases au démarrage et toutes les six heures. Lorsqu’une version plus récente est disponible, la barre de titre et **Settings → Updates** l’indiquent. Téléchargez et redémarrez depuis cet endroit.

Les mises à jour sont vérifiées avec la somme de contrôle de la version et ne touchent jamais à vos fichiers ni à vos préférences. La vérification peut aussi être lancée à la demande depuis **Settings → Updates**.

## Développement

```bash
npm install
npm start
```

Vérifications utiles :

```bash
node --check electron/main.js
powershell -ExecutionPolicy Bypass -File native/build.ps1
npm run build:win
```

La roue de bureau utilise un petit assistant natif. Il détecte les glissers globaux et possède la cible de dépôt OLE native ; Electron se contente de dessiner la roue au-dessus. `native/build.ps1` le compile avec le compilateur .NET Framework fourni avec Windows ; l’exécutable produit est copié automatiquement dans l’installateur.

## Créer un installateur Windows

```bash
npm run build:win
```

Les sorties sont écrites dans `dist/` :

- `Wheel-and-Form-Setup-<version>.exe` — installateur NSIS
- `latest.yml` et blockmap — métadonnées de mise à jour utilisées par les versions installées
- fichiers de l’application décompressés pour inspection locale

Pour créer et publier une version sur GitHub en une seule étape :

```powershell
$env:GH_TOKEN = "github-token-with-repo-scope"
npm run release:win
```

Le workflow GitHub Actions dans `.github/workflows/build.yml` compile le même installateur sur `windows-latest` et le téléverse comme artifact.

## Structure du projet

```text
electron/
  main.js                  Fenêtre Electron, zone de notification, IPC, fichiers et conversions
  desktop.js               Superposition de bureau, carte d’état, assistant de glisser natif
  preload.js               Pont sécurisé window.api
  settings.js              Préférences JSON
  updater.js               Vérification GitHub, téléchargement et installation
  converter/
    registry.js            Définitions des conversions, outils et actions
    engine.js              Détection des moteurs et exécution des processus
    pdf.js                 Outils PDF basés sur pdf-lib
    subtitle.js            Utilitaires de sous-titres
src/
  index.html               Coque de l’application
  styles.css               Design system Precision Workshop, coque, vues et file d’attente
  styles-wheel.css         Roue radiale et superposition de bureau
  styles-modal.css         Réglages et boîtes de dialogue des outils
  app.js                   File d’attente, vues, statistiques et activité
  interactions.js          Roues, glisser-déposer, actions et clavier
  wheel.js                 Géométrie et rendu de la roue radiale
  desktop.html/css/js      Superposition transparente de la roue système
  desktop-status.*         Carte de progression et de résultat
  settings.js              Réglages, installation des moteurs et état des mises à jour
  update.js                Pastille de mise à jour, invites et actions
  toolmodal.js             Options et aperçus des outils
  float.js                 Fenêtre d’aperçu flottante
native/
  WheelAndFormDragHook.cs  Détecteur de glisser natif et cible de dépôt OLE
  build.ps1                Compile l’assistant avec le compilateur .NET de Windows
site/                      Site produit statique, déployé par GitHub Pages
assets/                    Icône de l’application, marque et polices
```

## Site du produit

Le site statique se trouve dans [`site/`](site/) et est déployé par `.github/workflows/deploy-pages.yml`. Il utilise le même design system Precision Workshop, de vraies captures de l’application et des textes en anglais, vietnamien, japonais, chinois, coréen, espagnol, français et allemand.

Pour le prévisualiser localement :

```bash
python -m http.server 8123 --directory site
```

Puis ouvrez `http://127.0.0.1:8123/`.
